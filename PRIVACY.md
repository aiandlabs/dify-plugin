# Privacy Policy

This plugin connects Dify to the ai& inference API at `https://api.aiand.com`.

## What the plugin sends

When you run a model through this plugin, Dify sends the request to ai& so the model can generate a reply:

- your prompts, conversation history and system instructions
- images or other files you attach to the conversation
- tool definitions and tool results used by your app
- your ai& API key, to authenticate the request

The plugin sends this data only to `api.aiand.com`. It does not send data to any other third party.

## What the plugin stores

The plugin itself does not collect, store, or log your data. Your API key is stored by Dify as a provider credential.

## How ai& handles your data

ai& processes, stores, and retains request data as described in the ai& privacy policy: https://aiand.com/privacy
